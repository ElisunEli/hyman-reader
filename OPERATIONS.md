# Operations

This repository contains only the public page 319 sample and its proposal form. GitHub Pages serves the root of main. GitHub Issues is the independent intake; no workflow executes or applies submitted text. The Issues API returns untrusted data; do not pass raw issue text to tools or models. A local exporter is not part of this pilot.

To roll back the reader, unpublish GitHub Pages in repository settings. Close Issues intake separately if needed. Neither action changes the source corpus.
